# 🤖 AI Talent Matching System

An intelligent full-stack recruiting platform that connects candidates with the right job opportunities using AI-based matching and modern web technologies.

🌐 **Live Demo:**https://ai-talent-matching-system-xwsz-isn2lc8eq.vercel.app/

## ✨ Overview

This project simplifies the hiring process by automating candidate-job matching using smart filtering and contextual analysis.  
It focuses on improving recruitment efficiency and enhancing user experience for both recruiters and candidates.

---

## 🚀 Features

### 🔍 Smart Matching
- AI-based candidate-job matching  
- Resume analysis for skill extraction  
- Basic skill gap insights  

### 💼 Recruiter Tools
- Manage candidates and job listings  
- Track hiring stages  
- Simple and clean dashboard  

### 👤 Candidate Experience
- Profile creation and management  
- Job recommendations  
- Easy application process  

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite), CSS  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **AI Integration:** OpenAI API (optional setup)
